| 4 真正合排 | 两类算法测试比较独立与合排用料；浏览器项目型材结果同根原料包含不同窗型，玻璃按默认玻璃和磨砂玻璃分组。 |

| 7 迁移兼容 | 临时旧数据库测试迁移幂等、失败回滚、无主存档隔离及管理员归属分配；原版本项目文件结构仍走 validate 导入。未执行真实数据库升级。 |
| 8 全链路 | 后端回归、状态测试、双入口构建通过。浏览器验证客户→项目→窗型→单窗及项目排料、管理员窗型预览；390 像素视口下工作台和项目排料截图检查无页面横向溢出。 |
| 9 多种输出 | 单窗与项目两类排料均下载 CSV/JSON；检查打印媒体样式截图，项目输出显示窗型、楼层、房间、樘号。账号切换与草稿隔离通过状态测试和浏览器流程。 |
